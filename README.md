# ScienceHelpy

Библиотека научных статей, еженедельная подборка и помощник по PDF. Из каталога можно открыть статью на arXiv, сохранить её в библиотеку или начать диалог по ней. Можно также загружать свои PDF. «Обсудить с ИИ» открывает статью в новой вкладке помощника. Слева — чаты только по этой статье, в центре — переписка, справа — PDF с переходом к страницам из ответов. На узком экране эти области переключаются вкладками.

Каждая статья может иметь несколько независимых чатов. История переписки и ссылки на источники хранятся в `chats.sqlite3` рядом с журналом событий и остаются после перезагрузки страницы или сервера. Доступ к прошлым чатам привязан к cookie браузера. После очистки cookie и в другом браузере эти чаты недоступны.

## Локальный запуск

Python 3.11 или новее:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python web.py
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). В Windows активируйте окружение через `.venv\Scripts\activate`. В комплекте есть пять статей. Загружаемый PDF должен быть не больше 25 МиБ и 300 страниц. Для поиска нужен текстовый слой.

Переключатель RU/EN в шапке меняет язык каталога, помощника и подсказок. Язык ответа ИИ по-прежнему определяется языком вопроса. В форме импорта можно указать arXiv ID (например, `1706.03762` или `hep-th/9711200`) либо ссылку arXiv на аннотацию или PDF. После импорта PDF можно открыть или выбрать для обсуждения.

## Подборка недели

Источник — [Hugging Face Daily Papers](https://huggingface.co/papers). ScienceHelpy берёт записи за последнюю завершённую неделю по UTC, убирает дубли и сортирует по формуле «голоса + 2 × комментарии». Это популярность в сообществе Hugging Face. Список обновляется раз в неделю. При недоступности источника предыдущая подборка остаётся видимой, а фоновый процесс повторяет запрос через час. Сам PDF скачивается с arXiv по кнопке «Сохранить» или при открытии диалога по статье. Сохранённые PDF остаются в библиотеке после смены подборки.

Локальный `python web.py` запускает обновление в фоне. Отдельно можно выполнить `python -m weekly` для обновления сейчас или `python -m weekly --watch` для постоянно работающего обновления.

## Ответы ИИ

Без модели помощник находит фрагменты по ключевым словам и даёт ссылки на их страницы. Для ответов и уточняющих вопросов подключите одну модель через `.env` в корне проекта:

| Переменная | Назначение |
| --- | --- |
| `OPENROUTER_API_KEY` | Ключ OpenRouter. При его наличии приложение использует OpenRouter. В сервис передаются вопрос, до трёх недавних пар реплик и отобранные фрагменты. |
| `OPENROUTER_MODEL` | Идентификатор модели OpenRouter. По умолчанию `nvidia/nemotron-3-ultra-550b-a55b:free`. |
| `OPENROUTER_ENV_FILE` | Необязательный путь к существующему локальному `.env`. Из него читаются только настройки OpenRouter, которые не заданы напрямую. |
| `SCIENCEHELPY_OLLAMA_MODEL` | Имя локальной модели Ollama, например `qwen2.5:3b`. Модель нужно заранее загрузить в Ollama. |
| `SCIENCEHELPY_OLLAMA_URL` | Адрес запущенного Ollama. По умолчанию `http://127.0.0.1:11434`. |
| `GROQ_API` | Ключ Groq, если OpenRouter и Ollama не настроены. В Groq передаются вопрос, недавние реплики и отобранные фрагменты. |
| `MODEL_NAME` | Модель Groq. По умолчанию `llama-3.3-70b-versatile`. |
| `TAVILY_API` | Необязательный ключ для внешнего поиска в консоли при отсутствии локальных результатов. Диалог по выбранной статье веб-помощника использует её PDF. |
| `PATH_TO_PDFS` | Каталог PDF. По умолчанию `pdfs`. |
| `PATH_TO_PDFS_URL` | Список ссылок для `python main.py --import-papers`. По умолчанию `papers.txt`. |
| `SCIENCEHELPY_EVENTS_DB` | Путь к журналу событий и каталог хранения подборки. |

При недоступности модели интерфейс показывает найденные фрагменты. Консольный режим по-прежнему доступен через `python main.py`.

## Запуск на сервере

```sh
docker compose up --build -d
```

Compose запускает веб-приложение и отдельный процесс обновления. Подборка обновляется и без открытых вкладок. Именованные тома хранят библиотеку, чаты, журнал событий и подборку между перезапусками. Веб-сервис доступен на loopback-сокете хоста `127.0.0.1:8000`. Для доступа по домену настройте HTTPS-прокси с контролем доступа и укажите полный origin в `SCIENCEHELPY_PUBLIC_URL`, например `https://papers.example.org`. Прокси должен передавать исходный заголовок `Host`. Все посетители с доступом к развёртыванию используют общую библиотеку.

На сервере для ИИ можно передать `OPENROUTER_API_KEY` или `GROQ_API` через окружение Compose либо указать адрес Ollama, доступный из контейнера веб-приложения.
