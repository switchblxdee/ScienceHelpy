# ScienceHelpy

Локальная библиотека научных статей и помощник по работе с PDF. В интерфейсе можно отфильтровать каталог по названию, автору или arXiv ID, добавить свои PDF и искать фрагменты в одной статье или во всей библиотеке. Каждый результат указывает страницу исходного PDF. В репозитории есть пять статей для первого запуска.

## Запуск

Из папки проекта, с Python 3.11 или новее:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python web.py
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). В Windows используйте `.venv\Scripts\activate` для активации окружения. Веб-сервер предназначен для работы на своём компьютере.

Консольный режим использует ту же библиотеку и поиск:

```sh
python main.py
python main.py --import-papers
```

Вторая команда загружает PDF по ссылкам в локальном `papers.txt`. Строки соответствуют именам `1.pdf`, `2.pdf` и так далее. Уже существующие PDF пропускаются. В веб-интерфейсе можно добавлять PDF с компьютера. Файлы ограничены 25 МиБ и 300 страницами. Для поиска нужен текстовый слой, OCR не выполняется. Поиск учитывает слова вопроса, поэтому для англоязычных статей лучше вводить термины на английском.

## Настройки

По умолчанию каталог и поиск доступны без сервисных ключей. При необходимости создайте файл `.env` в корне проекта:

| Переменная | Назначение |
| --- | --- |
| `GROQ_API` | Ключ Groq для генерации ответа по найденным фрагментам. В сервис передаются вопрос и отобранные фрагменты. |
| `MODEL_NAME` | Идентификатор модели Groq. По умолчанию `llama-3.3-70b-versatile`. |
| `TAVILY_API` | Ключ Tavily для интернет-поиска, когда поиск по всей библиотеке не дал результатов. В сервис передаётся вопрос. |
| `PATH_TO_PDFS` | Каталог PDF. По умолчанию `pdfs`. |
| `PATH_TO_PDFS_URL` | Файл со списком ссылок для консольного импорта. По умолчанию `papers.txt`. |
| `SCIENCEHELPY_EVENTS_DB` | Путь к журналу событий. По умолчанию `.sciencehelpy/events.sqlite3`. |

При сбое Groq помощник показывает найденные фрагменты. Хранилище статьи и временные данные поиска находятся на компьютере пользователя.
